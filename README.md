## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Influence Tracker** | Monitor influence pool and track spending per diplomatic action |
| **Peace Planner** | Calculate influence cost for peace proposals and alliances |
| **Relation Log** | Log faction relationship changes and their causes |
| **Policy Manager** | Track kingdom policy votes and influence investment outcomes |
